# Personal Portfolio Website

## Overview

A responsive personal portfolio showcasing my software engineering projects, technical skills, achievements, certifications, and professional experience. The website provides recruiters and collaborators with quick access to my GitHub repositories, resume, and professional profiles.

---

## Features

- Responsive user interface
- About Me section
- Technical Skills
- Featured Projects
- Certifications & Achievements
- Resume download
- Contact information
- GitHub and LinkedIn integration

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
